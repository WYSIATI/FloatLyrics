## Privacy

Only a verified public documentation page is used in the wider work shots.
Browser tabs, profile controls, the system menu bar and other windows are
cropped out. The upcoming lyric in that shot is obscured. Settings and live
island footage use window-only captures that exclude other applications and
their backdrops. Native menu and control close-ups contain only Float Lyrics.
The export metadata contains the film title and production note, with no user
name, local path, account, device name or recording location.

Raw setup footage containing unrelated Mac content is excluded from source
control, release assets and the final film, and is removed after editing.
Only the completed film, poster, captions and checksums are published.

## Editing and instructions

The edit combines real recordings with held native menu/control captures. It
uses cuts between states, rather than pretending to be one continuous desktop
session. It contains no recreated workspace, replacement app UI or drawn cursor.
The numbered instructions explain player selection, starting playback,
Automation permission, notch controls, opacity, text color and installation.
All instructions are burned in and have matching SRT captions.
